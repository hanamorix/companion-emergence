**A1R.5** What "the same answer" compares: the emotion-to-strength map each site pools, taken by wrapping `aggregate_state` and capturing its return at each site (and `_peak_emotion` for the heartbeat summary, A1R.4), against one reference, `aggregate_state` over every active memory in the store. One test per (dataset, surface) cell. Rendered outputs are not compared, because they differ in shape (a dict, a text block, a boolean). The cell shape also keeps a strict expected failure on one surface from hiding a regression in another. Inside each cell the same purpose needs three rules, because a strict expected failure alone passes for any error: (1) the cell first checks, with `pytest.fail` and not `assert`, that its wrapper captured exactly one call on the dataset's store; (2) each strict mark carries `raises=AssertionError`, so only the comparison's own assertion counts as the expected failure, and a cell that raises anything else, or whose wrapper never fired, fails the run instead of showing XFAIL; (3) the wrapper patches the name the site looks up: the site module's attribute for a module-level import (`get_emotional_state.py:7`, `maker/sources.py:13`, `reflex.py:19`, `monologue/trace.py:14`), the source module (`brain.emotion.aggregate`) for a function-local import (`persona_state`, `prompt`, `supervisor`, `research`, `review`), and `HeartbeatEngine._peak_emotion` is replaced as a `staticmethod` (`heartbeat.py:1442`; a plain-function replacement receives `self`, raises `TypeError`, and `_write_daemon_state_for_heartbeat` swallows it at :1439, leaving an empty capture). Sites that return early without arcs or interests (`reflex.run_tick`, "no_arcs_defined" at `reflex.py:312-321`; research, "no_interests_defined" at `research.py:186`) get the arcs and interests their cell needs to reach the aggregate; `_build_emotions` and `_build_body` return `{}` or `None` on any exception (`persona_state.py:370-372`), which rule (1) catches. The checks sit inside the cells and add no test, so there is no test of a test. Decided by TRIO-1 (a), 3/3 for the cell shape.

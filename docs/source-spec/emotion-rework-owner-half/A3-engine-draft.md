- **E2.1** Formula, copied: `weight = weight × 0.5^(hours since last_update ÷ H) + w`, and `average = average × (weight − w) ÷ weight + new_value × w ÷ weight`. H is 24 h for the short average and 30 days for the long one, both dev constants.
  - The average line is built in the algebraically identical delta form `average = average + (new_value − average) × w ÷ weight`. **Reads.**
- **RD1** `read()` returns `(short, long, difference, shift)` for each present emotion, in one call. An emotion is present once it has had an entry, meaning its long weight is above 0. A zero entry never removes presence: a decayed emotion stays present at a small number. Readers use the difference as a size and its sign as where the feeling sits (RD2). The fourth value, `shift`, is +1 (a rising run), -1 (a falling run) or 0, as worked out from the snapshot (E1.5, E5.26): it is 0 while the start gate is closed (E5.25) and for a feeling whose long average has no finished run in the window.
